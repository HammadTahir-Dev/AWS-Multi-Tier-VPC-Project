# AWS Multi Tier VPC Architecture Project

## Overview
Designed and deployed a secure multi tier AWS infrastructure using public and private subnets.

## Objectives
- Build secure AWS networking
- Deploy public web server
- Isolate backend server
- Configure route tables and Internet Gateway
- Implement Security Groups

## AWS Services Used
- Amazon VPC
- Amazon EC2
- Security Groups
- Internet Gateway
- Route Tables
- Subnets

## Project Workflow
1. Created custom VPC
2. Configured public/private subnets
3. Attached Internet Gateway
4. Created route tables
5. Deployed EC2 web server
6. Configured backend private server
7. Installed Apache web server

## Security Implementation
- SSH restricted
- Private subnet isolation
- Security Group based access control

## Key Learnings
- Public vs private subnet architecture
- AWS networking fundamentals
- EC2 deployment
- Linux server configuration
